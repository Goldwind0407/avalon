# 單人電腦玩家：目前的中文決策規則

這份文件對照 `feature/solo-bots` 的目前實作，供不讀 Dart 的人查看、討論與調整設計方向。

**修改這份 Markdown 不會直接改變遊戲。策略仍由 Dart 執行；台詞來源改為 JSON，修改後須重新產生資料庫。** 資料格式、資訊權限與 V2 進度見 [實作契約](solo_bot_data_contract.md)。

## 先看這幾點

- 你是 1 號玩家，其餘 4～9 位是電腦。
- 電腦依自己允許知道的情報與公開紀錄決策，沒有取得全員身分表。
- 「懷疑分數」與「隊伍風險」是策略評分，不是真實身分機率或經過校正的勝率。
- 目前有基本行動、三種擴充、部分 V2 情境台詞、對邪惡席位組合的聯合推理、角色扮演（梅林偽裝、派西維爾跟隨梅林、莫甘娜裝好人）、六種風格與三種難度；尚未實作自由對話。
- `test/bot_selfplay_test.dart` 會讓電腦自己對打 900 局檢查打法是否合理（一般難度目前正義勝率約 5 人 34%、7 人 25%、10 人 22%）。調整策略後請看它印出的數字。

## 1. 每位電腦能知道什麼？

| 資訊 | 可否取得 | 說明 |
|---|---|---|
| 自己的角色、目前陣營 | 可以 | 蘭斯洛特會依本場的公開轉換狀態改變目標 |
| 該角色開局可見的席位 | 可以 | 梅林、派西維爾與邪惡角色取得的內容不同 |
| 每次提案的隊長、隊伍、公開投票 | 可以 | 全員投完後才成為公開紀錄 |
| 遠征隊伍、成功／失敗、失敗牌張數 | 可以 | 成功的遠征也可能出現失敗牌 |
| 自己出過的原始任務牌 | 可以 | 每位電腦只保存自己的牌 |
| 本人使用湖中女神的查驗結果 | 可以 | 別人的宣稱另存為公開發言 |
| 本人使用王者之劍看到的原始牌 | 可以 | 選擇翻誰之前不知道那張牌 |
| 其他玩家的完整角色或私人查驗 | 不可以 | 不會放進決策輸入 |
| 真人說進麥克風的內容 | 目前不可以 | 尚未加入語音辨識與自由語意理解 |

派西維爾看見兩個候選人時，不會直接知道誰是梅林、誰是莫甘娜。奧伯倫與邪惡蘭斯洛特也不會憑空取得邪惡隊友名單。

對應程式：[資訊快照](../lib/features/solo/bot_observation.dart)、[裁判如何提供每位玩家的資訊](../lib/features/solo/solo_session.dart)。

## 2. 怎麼判斷誰可疑？

文件以 0～100 分說明；程式內使用 0～1。

### 起始分數

未知玩家的起始懷疑分數：

```text
（本場邪惡人數 − 自己與已知席位的邪惡估計總和）÷ 其餘未知席位數 × 100

例如：5 人局有 2 位邪惡，自己是好人時，其餘 4 人先各給 50 分。
若自己是邪惡，其餘 4 人先各給 25 分。
```

電腦對自己的陣營沒有疑問：目前是正義就給自己 0 分，是邪惡就給自己 100 分。

角色可見席位與本人私人查驗先納入估計，再分配剩餘分數；派西維爾的兩位候選人起始各 50 分。

### 公開遠征紀錄

每次決策會重新查看歷史：

1. 先看失敗牌張數，而不只看遠征是否失敗。
2. 若用過王者之劍，保守扣掉一張可能由翻牌造成的失敗。
3. 若電腦自己出過失敗，而且自己的牌沒有被翻轉，再扣掉自己的貢獻。
4. 剩餘的失敗牌會提高其他隊員的懷疑分數：每位增加約 `18 × 剩餘失敗張數 ÷（隊伍人數－1）` 分。
5. 如果完全沒有失敗牌，而且沒有翻牌，每位其他隊員只降低 2.5 分。成功不是好人證明。
6. 有蘭斯洛特擴充，而且當時與目前的轉換狀態不同時，上述歷史加減分只取 40%。

例如：第四次遠征需要兩張失敗牌才算失敗，最後只有一張失敗。電腦仍會把那張牌當成推理線索。

### 公開投票紀錄

壞人知道同伴坐哪裡，會替有同伴的隊投贊成；好人不知道，所以公開的投票紀錄是全桌最重要的線索。這項在排除法之後才算，以「賠率」相乘（不是加減分），第五次提案是被迫通過的，不列入：

| 這個人做了什麼 | 是壞人的賠率 |
|---|---:|
| 提案被否決，他不在隊上卻投贊成 | × 3 |
| 提案被否決，他在隊上（不是隊長）投贊成 | × 2.2 |
| 提案被否決，他不在隊上投反對 | × 0.75 |
| 提案被否決，他在隊上卻投反對 | × 0.5 |
| 遠征有失敗牌，他不在隊上卻投過贊成 | × 1.5 |
| 遠征有失敗牌，他不在隊上投過反對 | × 0.4 |
| 遠征有失敗牌，他在隊上卻投過反對 | × 0.2 |

- 同一個人的多筆紀錄會相乘：在隊外贊成過兩支被否決的隊，賠率就是 × 9。
- 例：原本懷疑值 40 的人，在隊外贊成了一支被否決的隊，變成約 67；又反對了一支後來失敗的隊，回到約 44。
- 已經確定的人（100 或 0）不受影響。用過王者之劍的遠征不算「失敗的隊」。蘭斯洛特換邊前的紀錄一樣列入。
- 新手不看這項；一般與高手相同。
- 這些倍數比全電腦對局實際量到的保守很多（實測在隊外贊成被否決隊伍的人，約九成是壞人），免得你自己投票比較隨興時被電腦一口咬定。
- 電腦點名時會說出這個理由：「第 2 次遠征第 1 次提案被否決時，6 號不在隊上卻投了贊成」。

調整紀錄（同一批隨機對局，5 到 10 人、隨機擴充、有對話）：

| | 最初 | 加重失敗隊的投票 | 讀完整投票紀錄 | 現在 | 真人平台的參考值 |
|---|---:|---:|---:|---:|---:|
| 好人勝率 | 29% | 45% | 51% | 約 46% | 約 46% |
| 完成三次任務 | 55% | 72% | 81% | 約 78% | 68% |
| 完成後刺中梅林 | 48% | 38% | 37% | 約 41% | 約 34% |
| 第一次遠征失敗 | — | — | 37% | 28% | 17% |

「現在」是 1000 局與 2000 局兩批的平均（分別是 44% 和 48%）。參考值來自一份整理線上平台對局的文件，來源無法查證，只當方向用。和它相比，各人數的好人勝率大多在 ±6 個百分點內；9 人桌偏高（約 60%，參考值 47%），因為預設角色沒有莫甘娜，派西維爾一開局就確定誰是梅林。整體上電腦的好人比真人更會完成任務，所以勝負比較常落在刺殺。

用 `BALANCE_GAMES=1000 flutter test test/balance_test.dart` 可以重跑；加上 `BALANCE_DUMP=檔名` 會存下每局完整的組隊、投票與任務紀錄。

### 邏輯推理（排除法）

電腦會列出「邪惡席位的所有可能組合」，只留下符合自己確定知道的事與已出現的失敗牌的組合：

- 某人在所有可能組合中都是邪惡 → 100 分。例如兩人遠征失敗，隊上的好人確定另一人是邪惡。
- 某人在所有可能組合中都不是邪惡 → 0 分。例如邪惡席位已全部確定，其餘的人都是好人。
- 其餘的人：分數 = 25% 前面的評分 + 75% 他在可能組合中是邪惡的比例。
- 完全沒有失敗牌的遠征會讓隊員更可信：組合裡每多一位隊員是邪惡，權重乘上 0.2，因為他得忍住不出失敗。第一次遠征例外：邪惡常常潛伏，所以只乘上 0.7（7 人以下）或 0.45（8 人以上），也就是第一次遠征乾淨並不太能證明隊員是好人。
- 有失敗牌的遠征只當作「隊上至少有這麼多位邪惡」，不推論更多（邪惡會互相配合只出剛好的張數）。
- 用過王者之劍的遠征不參與排除。
- **有蘭斯洛特時**：除了邪惡席位，還會一起列出「誰可能是邪惡蘭斯洛特、誰可能是正義蘭斯洛特」。每次遠征用當時的陣營來檢查（換邊前邪惡蘭斯洛特算邪惡，換邊後正義蘭斯洛特算邪惡），所以換邊前的紀錄不會作廢。版本二裡在邪惡方的蘭斯洛特一定要出失敗，因此一次沒有失敗牌的遠征可以排除「隊上有當時在邪惡方的蘭斯洛特」。
- 梅林換邊後對他看見的壞人、以及換邊前的舊查驗，不再用固定的 65／35 分，而是交給這個排除法算（例如梅林看見三位壞人，換邊後每位大約有三分之一機會已經是好人，再依紀錄修正）。

### 自己的私人情報

| 情況 | 懷疑分數 |
|---|---:|
| 開局看見的邪惡玩家 | 100 |
| 梅林開局看見的邪惡玩家，但已發生不同的蘭斯洛特轉換狀態 | 起始 65，再由排除法修正 |
| 邪惡玩家開局認得的邪惡蘭斯洛特，換邊後 | 0（已是好人） |
| 派西維爾看見兩個候選人 | 各 50 |
| 派西維爾只看見一個候選人 | 0 |
| 本人查驗得到邪惡，且沒有轉換狀態差異 | 100 |
| 本人查驗得到正義，且沒有轉換狀態差異 | 0 |
| 舊查驗為邪惡，目前轉換狀態已不同 | 起始 65，再由排除法修正 |
| 舊查驗為正義，目前轉換狀態已不同 | 起始 35，再由排除法修正 |

王者之劍若讓本人看見一張原始失敗牌，也會作為該玩家「當時屬於邪惡」的私人線索。看見原始成功牌不會直接證明對方是正義。

派西維爾可排除自己的梅林候選人是蘭斯洛特，因此對候選人的合法私人查驗不會隨轉換而降級。一般玩家仍可能是蘭斯洛特，舊情報會保留不確定性；已有當前確定情報時，舊的不確定線索不會把它沖淡。

### 別人的發言

- 湖中女神宣稱整局都記得；轉換狀態不同的舊宣稱不採用。
- 越信任宣稱者，越願意調整被查驗者的分數（最多約 25 分）。
- 若有人公開支持包含高度可疑玩家的隊伍，對發言者增加 2.5 分懷疑。
- 公開宣稱不會覆蓋本人保有的私人情報評分。

對應程式：[BotBrain.suspicion](../lib/features/solo/bot_brain.dart)。

## 3. 隊長怎麼選隊？

電腦會列出所有符合人數的隊伍，逐隊評分，再選最高分。

```text
正義隊長：分數 = −隊伍風險 + 自己入隊加分 + 隨機變化
邪惡隊長：分數 = ＋隊伍風險 + 自己入隊加分 − 多帶同伴的扣分 − 0.6 × 這隊在不知情的人眼中的風險 + 隨機變化

邪惡隊長只帶剛好夠破壞的人數：隊上已知同伴（含自己）每超過所需失敗張數一位，扣 50 分。
邪惡隊長還會讓隊伍「看起來安全」：負責破壞的人以外，其餘隊員挑大家公認可信的人（例如剛從成功任務回來的），這樣提案比較容易通過。

自己入隊加 8 分；每隊再加 0～不到 6 分的隨機變化。
```

隊伍風險的計算方式：先把每人的懷疑值乘以 0.85，當成該人會出失敗的簡化估計，再計算隊伍出現足夠失敗牌的風險。需要兩張失敗的遠征，會使用兩張的門檻。

本人若是變體二必須出失敗的蘭斯洛特，會以確定失敗計算。本人已交出的當前任務牌也使用確定值；其他人的未公開任務牌不會取得。

這裡把各人的出牌當成獨立估計，尚未模擬完整的邪惡協作。隊長也不是必定把自己選進去，只是有加分。

對應程式：`teamRisk()`、`chooseTeam()`。

## 4. 怎麼投贊成／反對？

### 第五次提案

已連續否決四次時，所有電腦（包含邪惡）都投贊成。邪惡是少數，擋不下這次提案，而投票是公開的，反對只會暴露身分。

### 第一次遠征

還沒有任何任務結果時，大家都沒有理由反對：

- 邪惡電腦不論風格，都有 90% 機率贊成第一輪的隊伍（反對第一隊太顯眼）。
- 梅林看到第一隊有壞人時，至少有 60% 機率跟著大家贊成（第一輪就反對，等於告訴刺客他知道內情）。
- 發言只說一句簡短的話，例如「第一輪沒什麼資訊，我沒意見，讓它出發吧」，不談還不存在的紀錄。這一輪被點名或被問問題時照常回應。

### 正義電腦

1. 只需一張失敗牌的任務，隊上有人超過當前難度的嫌疑門檻（新手 80／一般 62／高手 55 分）便反對；需兩張失敗的任務依整隊風險判斷。
2. 否則和「自己會派的最安全隊伍」比較：這隊的風險不比它高出容許值，就贊成。

| 情況 | 容許值 |
|---|---:|
| 還沒有任何遠征結果 | 30 |
| 一般局勢 | 10 |
| 已有兩次遠征失敗 | 5 |
| 每多一次連續否決 | 一般 +4；已失敗兩次時 +3 |
| 隊長的可信度 | 加上（本場邪惡比例 − 隊長懷疑值）× 30：信任的隊長放寬，懷疑的隊長收緊 |

### 邪惡電腦

1. 隊伍風險大於 45（多半是隊上有同伴）：先看「不知情的人坐在我這個位子會怎麼投」。
   - 不知情的人也會贊成：贊成。
   - 不知情的人會反對：只有一部分機會硬投贊成，其餘跟著反對，免得每次都替同伴的隊護航而露餡。

   | 情況 | 硬投贊成的機會 |
   |---|---:|
   | 不在隊上，這次遠征已被否決 0 或 1 次 | 15% |
   | 不在隊上，已被否決 2 次 | 30% |
   | 不在隊上，已被否決 3 次 | 50% |
   | 自己在隊上 | 50% |
   | 再失敗一次邪惡就贏 | 85% |

   風格與難度會調整這個機會（越會偽裝的越少硬投）。
2. 其他情況（破壞不了的隊）：自己在隊上時九成贊成（反對自己的隊太顯眼）；不在隊上時為了混入好人，有時也贊成：第一、二次遠征 55%，之後 30%；正義已成功兩次時只有 10%。

同一提案的所有 BOT 投票決定，在第一位發言前就固定。若公開表示支持／反對，會與實際投票一致；中性發言不會把預定投票寫進公開欄位。新提案才重新決定。

例子：隊伍風險是 55，一般局勢的正義電腦會贊成；若已失敗兩次、目前沒有連續否決，則會反對。

對應程式：`vote()`、`SoloGameSession._plannedVote()`。

## 5. 任務牌怎麼出？

依下面順序判斷，前面的條件優先：

| 優先順序 | 情況 | 決定 |
|---|---|---|
| 1 | 目前是正義 | 一定出成功 |
| 2 | 使用蘭斯洛特變體二，目前是邪惡蘭斯洛特 | 一定出失敗 |
| 3 | 已知同隊邪惡至少兩人，而且足以達到失敗門檻 | 依席位排序，前面所需人數一定出失敗，多餘隊員出成功 |
| 4 | 本次需要兩張失敗，而隊上沒有第二位已知同伴 | 隊上另有懷疑值 50 以上的人（可能補上第二張）才出失敗，否則出成功，不白白暴露 |
| 4a | 開了王者之劍、劍在自己手上、隊上沒有其他同伴 | 自己出成功，再用劍把一位好人的成功翻成失敗（挑大家本來就比較懷疑的那位）。任務照樣失敗，檯面上那張失敗牌卻不是他的 |
| 4b | 其餘情況，任一陣營已贏兩次遠征 | 出失敗，優先爭取關鍵遠征 |
| 5 | 其餘邪惡玩家、第一次遠征 | 7 人以下：70% 成功（潛伏騙取信任）；8 人以上：45% 成功 |
| 5a | 蘭斯洛特變體一的邪惡蘭斯洛特、第一、二次遠征 | 成功機率再加 60 個百分點：第三次遠征起才會翻轉換牌，他之後可能變成好人，先把紀錄保持乾淨 |
| 6 | 其餘邪惡玩家、後續遠征 | 16% 成功、84% 失敗 |
| 7 | 上述可藏牌情況，劍在其他高度可信的好人手上 | 成功藏牌機率再加 20 個百分點 |

協作名單只採用本人、角色可見且目前仍確定的隊友，以及本人合法取得的當前邪惡查驗。不以公開懷疑分數高低冒充已知隊友。

協作是一條席位慣例，並非秘密交換出牌計畫。被指定破壞者不再隨機藏牌；不知道完整隊友名單的角色仍可能無法協作。強制失敗的蘭斯洛特優先遵守規則。

對應程式：`questCard()`。

## 6. 湖中女神

### 選擇查驗對象

- 排除所有曾持有湖中女神的玩家。
- 目前是邪惡且認得同伴的持有者：一半機率查同伴、一半機率查好人（見第 13 節）。
- 其他持有者：越接近 50 分懷疑的對象，越有查驗價值。
- 參加過越多次遠征，略微增加優先度。
- 相同資訊價值時，以隨機打散的順序參與選擇。

### 公開怎麼說

- 目前是正義的 BOT：如實宣稱。
- 目前是邪惡的 BOT：查到邪惡同伴時 90% 說他是正義（掩護）；查到正義玩家時依風格 15～65% 說他是邪惡（栽贓）。
- 查驗的真實結果只進入持有者的私人記憶；其他人收到的是可能有假的公開宣稱。

對應程式：`ladyTarget()`、`SoloGameSession._rememberReveal()`。

## 7. 蘭斯洛特

- 依現有規則引擎的兩種變體運作，不另造一套轉換規則。
- 決策使用目前陣營；初始正義蘭斯洛特換成邪惡後，會改用邪惡策略，反之亦然。
- 變體二的邪惡蘭斯洛特遵守強制失敗規則。
- 舊查驗與歷史推理會依轉換狀態降低確定性。
- 邪惡玩家（奧伯倫與邪惡蘭斯洛特除外）開局就知道哪位同伴是邪惡蘭斯洛特。換邊後，他們把蘭斯洛特改視為好人，其餘同伴仍是確定的同伴，繼續配合出牌。
- 梅林看得到邪惡蘭斯洛特是壞人，但分不出是哪一位；換邊後，他看到的每位壞人都降為 65 分。
- 公開翻出轉換牌，不代表正義玩家知道兩位蘭斯洛特坐在哪裡。
- 目前尚未利用已公開的未來轉換牌進行多輪戰略規劃。

對應程式：`BotObservation.mustFail`、`suspicion()`；轉換本身由 `game_model.dart` 處理。

## 8. 王者之劍

### 隊長交劍

- 只考慮隊伍內、隊長以外的隊員。
- 正義隊長交給懷疑值最低的人。
- 邪惡隊長交給懷疑值最高的人。

### 持劍者使用

- 不能翻自己的牌。
- 逐一比較不翻牌與翻轉各位其他隊員後的預期遠征結果。
- 正義選擇降低失敗風險最多的對象；邪惡選擇提高失敗風險最多的對象。
- 計算包含失敗門檻、本人已交出的牌及可能的成功→失敗／失敗→成功；沒有正收益就放棄。
- 選定前不知道對方實際出牌；翻轉後，持劍者才得到原始牌的私人資訊。

因此 BOT 可能翻錯牌，這是基於不完整資訊的選擇。

對應程式：`swordHolder()`、`swordTarget()`。

## 9. 刺客怎麼找梅林？

先排除自己，以及開局已認得的邪惡玩家。對剩下的人計分：基礎分數是 `100 − 懷疑分數`（越像好人越高），再依每次提案的隊長與投票加減分，最後加上隨機分數，刺殺最高分者。第五次提案（全員贊成）不列入。

「隊上有沒有邪惡」以刺客自己和他認得的同伴為準。有莫德雷德時，梅林看不到他：一支隊伍若只有一位同伴、而那位可能就是莫德雷德，只按「他不是莫德雷德」的機率算成有邪惡（例如刺客認得兩位同伴，就算一半）。加減分的細節與隨機幅度依難度不同，見第 13 節的表。

這是「誰的公開選擇看起來有情報」的推測，不會直接查看梅林身分。

對應程式：`assassinate()`。

## 10. 發言內容目前有哪些？

### 直接點名（優先）

電腦輪到發言時，先看公開紀錄有沒有能點名的理由，有的話用自己的話直接說：

- 理由只來自大家都看得到的紀錄：某人在失敗的隊伍上；或某人不在隊上卻贊成了後來失敗的隊伍（全員贊成的那次不算）。
- 好人點名自己最懷疑的人（懷疑分數 45 以上）；壞人挑公開看起來可疑的好人栽贓（30 以上），絕不點名同伴。梅林、派西維爾只用公開紀錄判斷，不會說出私人情報。
- 前面有人指控某人時：同樣懷疑的會附和（「我同意 3 號，…」）；被指控的是自己的同伴，或是自己相信的好人（參加過乾淨的任務、懷疑分數 20 以下），會出面辯護。
- 句尾和自己的票一致：被點名的人在隊上就說會反對；不在隊上而且自己贊成，就說這隊可以接受。點名的人在隊上卻要投贊成時，不會點名他。
- 敢不敢點名依風格：衝動型、激進型八成，謹慎型四成，跟票型五成，其他六成；新手再打八折。
- 這一輪被別人問到問題的電腦，會先回答問題，不點名。回答會盡量具體：隊長被問就說明選人理由；被問「當時為什麼反對那支成功的隊」就說明當時的顧慮。
- 同一個人已經被兩個人點名後，後面附和的只說一句短的（「3號我也不放心」）；到第四個人就不再附和。
- 被點名的人會用紀錄替自己辯護：那次隊上還有誰、當時還有誰也投了贊成；兩人隊失敗時會說「我出的是成功，該解釋的是他」。
- 台詞裡一律用座位號碼稱呼（「3號」），不念完整名牌。

### 引用紀錄（沒有人可點名時，約七成半的機會）

沒有可點名的對象時，電腦多半會說一件「實際發生過的事」來解釋自己的票，全部來自公開紀錄：

| 情況 | 說什麼 |
|---|---|
| 自己是隊長 | 逐一說明選人理由：誰出任務沒有失敗牌、誰當時反對了後來失敗的隊、誰還沒出過任務；上一隊被換掉的人待過失敗的隊也會說 |
| 贊成 | 「這次把 X 換掉了，第 N 次出失敗牌時他在隊上」；「X、Y 第 N 次出任務沒有失敗牌」；隊上有人待過失敗的隊但仍贊成時，會說明「那隊不只他一個」 |
| 反對 | 「這隊有 X，第 N 次出失敗牌時他在隊上」；「這隊跟第 N 次失敗的那隊重複了 X、Y」；「有成功紀錄的 X 不帶，改帶沒出過任務的 Y」；「我不在隊上，裡面的人我沒辦法保證」 |
| 自己過去的票 | 反對過後來失敗的隊：「我當時就不贊成」；贊成過：「那一票我看走眼了」（各說一次） |
| 別人過去的票 | 上一次任務成功，卻只有一兩個人投反對：直接問他當時在擔心什麼；兩個人在三次以上有分歧的投票裡從沒分開過：點出來 |
| 兩人隊失敗 | 自己在隊上：「失敗牌不是我出的，那就只能是他」；不在隊上：「壞人至少有一個在裡面」 |

- 前一位已經說過同一件事時，下一位只說「我跟 N 號想的一樣」加一句短的，不再重複整段；第三位就換別的說。
- 壞人不會把紀錄指向同伴；也不會一邊點名某人、一邊贊成有他的隊。
- 第五次提案、上一次任務用了王者之劍或湖中女神時，引用紀錄的機會降到三成半，讓台詞庫裡對應的台詞有機會出現。
- 內容在 [bot_voice_points.dart](../lib/features/solo/bot_voice_points.dart)，複盤裡標示為「引用紀錄」。

### 提起舊局（固定人物的記憶）

- 單人模式的電腦是九位固定人物（見第 14 節）。每局打完會存檔，並記下每位電腦和你之間發生的事：你當壞人時他讓你出了任務、他看穿你、他錯怪你、他栽贓你、你冤枉他、你抓到他、你替壞人的他擔保、你讓壞人的他出任務、刺客刺中或刺錯、同陣營輸贏。
- 下一局的第一次遠征（本來只會說「沒意見」的時候），同桌的電腦可能提起上一局：上一局的事七成機會、更早的三成，只有輸贏可講時再減半；每位電腦每局最多提一次，同一輪最多兩位。
- 你點名某位電腦時，如果上一局你也冤枉過他，他會先回一句「上一局你也說我有問題，結果我是好人」；電腦點名你時，如果上一局被你騙過，會補一句「上一局我就是太相信他」。每局各一次。
- 記憶只來自**已經結束、身分已公開**的對局，只影響台詞，不影響懷疑分數、投票或選隊，也不會透露這一局任何人的身分。
- 最多保留最近 40 局；在「對局紀錄」可以逐局刪除或全部清除，清除後電腦就忘了。
- 台詞在 [social_memory.dart](../lib/features/solo/memory/social_memory.dart) 的 `memoryLines()`，複盤裡標示為「提起舊局」。

### 跳身分：宣稱自己是派西維爾

只在這一局同時有派西維爾和莫甘娜時發生。宣稱不是證據，每個人都只能照說話者的紀錄決定信多少。

**誰會跳**

| 誰 | 什麼時候 | 說什麼 |
|---|---|---|
| 真派西維爾 | 壞人已拿下 2 次失敗，他認定的莫甘娜在隊上或當隊長，而且紀錄已經把兩位候選人分得夠開 | 「我是派西維爾。我看到的兩個人裡，X 是莫甘娜：…。另一位是誰我不會說。」 |
| 真派西維爾（反駁） | 有別人先跳 | 「我才是派西維爾，X 在說謊。」如果先跳的是他兩位候選人之一、而且點名的正是另一位，他會當成梅林在幫忙，不出聲 |
| 莫甘娜 | 被跳出來的人點名（八成機會）；或同一次遠征被兩人以上點名時先跳（三成） | 反過來說對方才是莫甘娜；先跳時把莫甘娜的帽子扣到公開紀錄最差的好人頭上 |
| 梅林 | 壞人已拿下 2 次失敗、隊上有他看得到的壞人（一成機會） | 假裝派西維爾去點名那個壞人。他不知道對方是不是莫甘娜，所以是賭博 |

- 每位電腦每局最多跳一次；指某人是莫甘娜的同時不會贊成有他的隊。
- 被點名成莫甘娜的人會否認一次。梅林被真派西維爾認錯時只說「你認錯人了」，不會反咬。

**其他人怎麼算**

- **只有一人跳**：越相信說話者，被點名者的懷疑分數加越多（說話者懷疑值 0.3 時約 +0.35，0.5 時約 +0.15）。
- **兩人對跳**：最多一個是真的。紀錄較差的那位懷疑值 +0.25，較可信那位的點名打七折計入。
- **自己被點名成莫甘娜的好人**：確定對方說謊（懷疑值至少 0.95）。
- **真派西維爾**：不在他兩位候選人裡的宣稱者一定是壞人；候選人之一指他是莫甘娜，那位就是莫甘娜、另一位就是梅林。
- **壞人**：本來就知道誰是誰，不受影響；台詞上會挺自己的同伴。
- **刺客**：宣稱者點名的是刺客的同伴 → 多半是派西維爾，降低他是梅林的分數；宣稱者說刺客本人是莫甘娜 → 知道他是壞人卻弄錯角色，這是梅林才會犯的錯；好人宣稱者點名了另一個好人 → 派西維爾把梅林認成莫甘娜，被點名的就是梅林。
- 後面發言的人會引用：「4 號跳派西維爾，說 2 號是莫甘娜。分清楚之前，有 2 號的隊我不跟」、「2 號和 5 號都說自己是派西維爾，一定有一個在說謊。…我先信 2 號」（全桌每局最多三次）。

同一批 1000 局逐局比對（有跳和不跳）：約 18% 的局有人跳、11% 有對跳。梅林假跳時好人勝率 22% 對 11%；莫甘娜跳時 30% 對 32%；真派西維爾跳時 19% 對 21%（任務完成率不變，但等於告訴刺客梅林是別人）。整體好人勝率不變。

對應程式：[bot_voice_claims.dart](../lib/features/solo/bot_voice_claims.dart) 的 `claim()`、[bot_brain.dart](../lib/features/solo/bot_brain.dart) 的 `_weighClaims()`／`_checkClaims()`／`assassinate()`。機率在 `BotVoice.percivalClaimChance` 等三個常數。複盤裡標示為「跳身分」。

### 台詞庫（其餘情況）

同一輪裡已經有人用過的那組台詞，後面的人會避開，不會出現三四個人輪流講同一句話的換句話說。


V2 草案的 105 組、420 句台詞已轉入正式資料格式。其中 104 組已登錄執行條件；只有「故意表態與投票不一致」的 G23 保持停用，要求最後公開立場與實際票一致；討論中可以重評，但改票須公開改口。

- 先檢查當前階段、角色／目前陣營、預定立場與所需證據，再選句子。
- 能引用換人、連續四次否決、成功但有失敗牌、兩次已公開投票的立場變化、本人查驗、翻劍與轉換事件等情境。
- 引用遠征時優先找與本次隊伍相關且較近的紀錄，不再固定只用第一場。
- 人名會完整顯示為 `3 號 【小明】`；缺少必要人物或事件時，那一句不會顯示。
- 公開問句可帶收件席位；輪到被問者時，可透過結構化紀錄回覆。這不是解析任意聊天文字。
- 會記錄誰質疑誰、誰替誰辯護、誰引用哪次事件。追問對準實際發言者，並區分被談論的對象。
- 女神宣稱可比較同一事件的矛盾說法；舊查驗會檢查後續轉換的時間與奇偶狀態。引述不算本人宣稱親眼看見。
- 刺客確定目標並完成刺殺後，才會加入對應目標的公開宣言。
- 同一重點會依最近兩次提案的發言記憶扣分，降低重複。同一輪別人說過的句子不會再說；別人用過的發言類型每次扣 12 分。決策與台詞使用不同亂數流。
- 台詞庫的句子有 35% 機率依風格加上口氣詞（例如衝動型「說真的，」、謹慎型「這個嘛，」）。
- 女神宣稱與真人發言也有局號、提案次序與公開證據欄位；宣稱不會變成本人查驗的真相。
- 沒有符合條件的台詞時，用簡短的支持／反對句子，不會填造證據。

對應程式：[台詞規劃器](../lib/features/solo/dialogue/bot_dialogue_planner.dart)、[條件與綁定](../lib/features/solo/dialogue/bot_dialogue_context.dart)、`DiscussionStatement`。完整格式及啟用清單見 [實作契約](solo_bot_data_contract.md)。

### 你的發言

輪到你時按「我要發言」自由打字（打字期間發言計時與電腦都會暫停），送出前會顯示「電腦會理解成：…」。電腦從文字找座位號碼（「3號」）或暱稱，再依關鍵字判斷：

| 讀到的意思 | 關鍵字 | 電腦怎麼看 |
|---|---|---|
| 懷疑某人 | 懷疑、壞人、可疑、有問題、不相信… | 被點名者的懷疑分數上升，幅度看電腦有多信任你（最多約 11 分）；被點名的電腦或他的同伴可能出面辯護，其他人可能附和 |
| 相信某人 | 相信、好人、不是壞人、清白… | 被點名者的懷疑分數下降，幅度同上 |
| 問某人 | ？、為什麼、怎麼、解釋… | 被問的電腦輪到發言時會先回答 |
| 宣稱好人 | 我是好人、相信我（沒有點名時） | 公開宣稱，不會直接改變判斷 |
| 跳派西維爾 | 我是派西維爾、我跳派西、我才是派西維爾；加上「3號是莫甘娜」就是點名 | 和電腦跳身分一樣處理（見上一節）：被點名者的懷疑分數上升、被點名的電腦會否認或反跳、刺客也會參考。只說「5號是梅林」不算點名莫甘娜 |
| 表態 | 支持、同意／反對、換人 | 只是發言，不會結束你的回合 |
| 其他 | — | 只會顯示，不影響判斷 |

最後按「我支持這隊／我想換人」表態並結束發言。

電腦也會用同樣的方式解讀彼此的點名與辯護。

## 11. 操作節奏

- 一般 BOT 操作預設間隔約 450 毫秒。
- BOT 每次發言依長度顯示：至少 7 秒，25 字以上每多一字加 0.2 秒，最多 14 秒。玩家可以按「下一位電腦」提早跳過。
- 投票與遠征結果由真人按繼續，保留觀看翻牌的時間。
- 開啟討論紀錄、筆記、規則、離開確認或進入背景，會暫停 BOT 操作與發言倒數。
- 結算後可以重新發牌；新一局會清除電腦記憶、發言與預定投票。

## 13. 各角色的打法

下表的機率是「一般」難度；「演戲」類的行為會乘上難度的演戲係數（新手 0、一般 1、高手 1.6）。

| 角色 | 打法 |
|---|---|
| 梅林 | 投票偽裝：若「一般忠臣會怎麼投」與照情報的投法不同，有機率照忠臣的投法。機率 = 風格偽裝值 × 演戲係數 × 6，放行可疑隊伍再 × 0.8、否決乾淨隊伍 × 1.3，上限 85%；已有一次遠征失敗時減半，兩次失敗時不偽裝。另外，第一次遠征之後、同一次遠征被否決不超過兩次時，他有 50% × 演戲係數的機率反對一支他明知乾淨的隊（代價只是多一次提案，卻讓他的票不那麼準）。當隊長時，在還沒有失敗且正義成功不到兩次的階段，也可能照忠臣視角選隊 |
| 派西維爾 | 排除法會用上「兩位候選人恰好一位是莫甘娜」：其中一位被證明是邪惡，另一位就確定是梅林。隊長是候選人時，隊長可信度對投票的影響加重（係數 +0.5） |
| 亞瑟的忠臣 | 基本推理與投票，沒有額外行為 |
| 刺客 | 遊戲中照一般邪惡打法。刺殺時依難度判斷誰像梅林（見下表），並且把自己也算進「隊上有邪惡」 |
| 莫甘娜 | 裝成梅林：正義成功不到兩次時贊成乾淨隊伍 +20 個百分點；第一、二次遠征藏牌 +15 個百分點；前兩次遠征當隊長且還沒有失敗時，60% 機率帶「自己 + 大家最信任的人」的乾淨隊 |
| 莫德雷德 | 梅林看不到他，所以比較敢出頭：當隊長時自己入隊加分 +10；正義成功不到兩次時贊成乾淨隊伍 +10 個百分點 |
| 奧伯倫、邪惡蘭斯洛特 | 沒有同伴知道要替他出失敗或掩護，藏牌機率 −8 個百分點 |
| 莫德雷德的爪牙 | 基本邪惡打法 |
| 所有邪惡 | 兩人遠征出失敗會讓隊友確定是誰，藏牌 +10 個百分點；拿到湖中女神時，一半機率查同伴（再宣稱他是好人，女神留在邪惡手上），一半機率查好人（可以栽贓） |

刺客判斷梅林的方式：

| 難度 | 看什麼 | 隨機幅度 |
|---|---|---:|
| 新手 | 誰當隊長時帶的隊沒有邪惡（每次 +25） | 0～70 |
| 一般 | 帶乾淨的隊 +20、帶有邪惡的隊 −10；反對有邪惡的隊 +8（自己在隊上還反對 +12）、贊成有邪惡的隊 −6；贊成乾淨的隊 +6 | 0～45 |
| 高手 | 帶乾淨的隊 +25、帶有邪惡的隊 −50；反對有邪惡的隊 +18（自己在隊上 +35），第一、二次遠征再 × 1.3；贊成有邪惡的隊 −35；贊成乾淨的隊 +5、反對乾淨的隊 −5 | 0～20 |

## 14. 風格

單人模式的電腦是九位固定人物，每位有固定的名字和風格；每局從中挑出需要的人數（風格盡量不重複），角色則每局重新抽。在設定畫面點電腦的名字可以看介紹和你們的對戰紀錄。風格只改變偏好，不給額外情報。遊戲結束揭曉身分時，名字後面會顯示該電腦的風格。

| 人物 | 風格 | 介紹 |
|---|---|---|
| 老陳 | 謹慎型 | 想清楚才投票，很少第一個表態 |
| 小魚 | 衝動型 | 想到什麼說什麼，隊伍差不多就讓它過 |
| 佩佩 | 跟票型 | 相信誰就跟誰，很重視隊長的說法 |
| 阿哲 | 邏輯型 | 只看紀錄，會把每一張票對過一遍 |
| 米亞 | 演技型 | 很會演，拿到壞人牌也看不出來 |
| 阿凱 | 激進型 | 講話直接，懷疑誰就當面點名 |
| 蓉蓉 | 邏輯型 | 話不多，開口通常有憑有據 |
| 大衛 | 演技型 | 笑笑的，什麼牌都說自己是好人 |
| 小虎 | 衝動型 | 容易被說服，也容易衝動反對 |

| 風格 | 特色 | 贊成容許值 | 跟隨隊長 | 選隊隨機 | 邪惡贊成乾淨隊 | 藏牌 | 女神栽贓 | 梅林偽裝 |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| 謹慎型 | 不輕易贊成，只派最信任的人 | −5 | ×1 | 3 | ×1.2 | +8 | 15% | 20% |
| 衝動型 | 容易贊成，選隊比較隨興 | +8 | ×1 | 16 | ×0.9 | −4 | 40% | 15% |
| 跟票型 | 信任的隊長說什麼就跟什麼 | +3 | ×2.2 | 6 | ×1 | 0 | 25% | 30% |
| 邏輯型 | 照紀錄推理，立場很少變 | 0 | ×0.8 | 2 | ×1 | 0 | 30% | 30% |
| 演技型 | 當邪惡時前期裝好人，關鍵局才破壞 | 0 | ×1 | 6 | ×1.5 | +20 | 25% | 45% |
| 激進型 | 當邪惡時有機會就破壞、栽贓 | −2 | ×1 | 6 | ×0.5 | −12 | 65% | 15% |

數值定義在 [bot_style.dart](../lib/features/solo/bot_style.dart)；測試用的「均衡型」全部是基準值（梅林偽裝 0）。

## 15. 難度

在「跟電腦遊玩」設定畫面標題旁選擇，套用到該局所有電腦（隊友和對手都是）。難度只改變電腦怎麼運用情報，不給額外情報。

| 項目 | 新手 | 一般 | 高手 |
|---|---:|---:|---:|
| 推理比重（排除法算出的比例佔懷疑分數多少；確定的結論三種難度都會下） | 55% | 75% | 90% |
| 「誰贊成了失敗的隊」的加減分 | 不看 | ×1 | ×1.5 |
| 湖中女神宣稱 | 只看當輪，最多 10 分 | 整局記得，最多 25 分 | 整局記得，最多 30 分 |
| 演戲係數（梅林偽裝、派西維爾跟隨、莫甘娜裝梅林、兩人遠征藏牌） | 0 | 1 | 1.6 |
| 選隊隨機幅度 | ×2.2 | ×1 | ×0.5 |
| 好人投票失誤（直接投反） | 5% | 0 | 0 |
| 邪惡贊成乾淨隊伍 | ×0.4（容易被看穿） | ×1 | ×1.1 |
| 邪惡隊長多帶一位同伴的扣分 | 15（偶爾會多帶） | 50 | 60 |
| 刺客 | 見第 13 節 | | |

自我對打（各 300 局、同難度對同難度）的正義勝率：新手 34%／15%／15%，一般 34%／25%／22%，高手 30%／23%／20%（5／7／10 人）。把其中一方換成不同難度時，方向符合預期：好人換成新手勝率明顯下降，邪惡換成新手正義勝率上升，邪惡換成高手正義勝率下降；好人換成高手的提升很小。

數值定義在 [bot_difficulty.dart](../lib/features/solo/bot_difficulty.dart)。

## 16. 已知還不像真人的地方

- 人數多時正義偏弱（7、10 人局勝率約兩成），新手難度更明顯。
- 高手好人相對一般好人的優勢很小。
- 風格還不影響台詞語氣。
- 真人的湖中女神結果沒有管道公開宣稱。

這些策略的目的，是讓電腦合法、獨立地完成整場遊戲，並且打法大致合理。後續可以依實際試玩調整權重、增加台詞與推理方式。
