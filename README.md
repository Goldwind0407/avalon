# Avalon — 暗影議會

繁體中文 Flutter 阿瓦隆 App，提供 **5～10 人同機傳遞遊玩**。大家在現場討論，依提示把手機交給指定玩家，秘密查看身分、投票及執行任務。

## 啟動

已包含 Android、iOS、Web 啟動專案。建議使用 Flutter 3.41 或更新的相容版本。

```sh
flutter pub get
flutter run -d chrome
```

手機遊玩：連接 Android 裝置或開啟模擬器後執行 `flutter run`。iOS 需在 macOS 使用 Xcode 建置。

## 遊玩流程

1. 在首頁選擇「一機遊玩」，直接進入設定，不需建立房間。
2. 選擇 5～10 人，點選玩家暱稱即可修改；玩家和角色配置同頁顯示，無需捲動。
3. 配置角色；梅林與刺客固定加入，派西維爾、莫甘娜、莫德雷德、奧伯倫可選。其餘名額自動補忠臣與爪牙。
4. 點「開始遊戲」直接發牌。依序傳遞手機，秘密查看身分與情報。
5. 隨機決定首任隊長，隊長組隊後全員秘密投票。公布每位玩家的贊成／反對；過半贊成才通過，平票否決。
6. 任務隊員秘密出成功或失敗。正義玩家只能出成功，邪惡玩家可自由選擇。只公布總票數。
7. 正義三次任務成功後進入刺殺；刺客命中梅林則邪惡勝，否則正義勝。三次任務失敗或連續五次組隊遭否決，邪惡直接獲勝。

七人以上第四次任務需兩張失敗票才會失敗。每次否決或完成任務後由下一位玩家擔任隊長；任務獲准執行時重設連續否決次數。

## 隱私與限制

- 每次秘密操作都有交接遮罩；App 進入背景時重新隱藏秘密畫面。
- 同機模式適合彼此信任的現場玩家，無防窺、截圖阻擋或伺服器保密機制。
- 玩家設定與角色只存放於本機記憶體，不支援跨手機連線、登入、聊天、語音或戰績。「多機遊玩」目前顯示尚未開放提示。
- 返回設定會結束對局；重新發牌、關閉 App 後不保留對局進度。
- 尚未實作湖中女神等擴充規則。平台檔案使用 Flutter 標準圖示與開發用應用程式識別碼，尚未配置商店發布簽章。

## 驗證

```sh
flutter analyze
flutter test
flutter build web
```

測試涵蓋陣營配額、角色視野、組隊與平票、連續否決、任務門檻、刺殺結局，以及建房、玩家新增與秘密發牌畫面。

## 程式結構

- `lib/core/`：主題與共用元件。
- `lib/features/home/`：首頁及本機房間入口。
- `lib/features/lobby/`：玩家、角色配置與開局驗證。
- `lib/features/game/game_model.dart`：遊戲狀態與規則。
- `lib/features/game/game_screen.dart`：同機交接、秘密操作與結果畫面。

遊戲背景與人數可參考 [Indie Boards & Cards 官方介紹](https://indieboardsandcards.com/our-games/the-resistance-avalon/)。本專案未包含官方插畫及 Logo。
